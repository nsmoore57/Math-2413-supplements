    Worksheet Definite Integrals

    Derivation 1 Finite Summation Formulas.

    First we need to discuss finite sums, as we will use them later in the section to calculate areas under curves. Let us start with the following summation formulas.
    \begin{equation} \sum_{k=1}^{N}1=\underbrace{1+1+\cdots+1}_{N\text{ times}}=N\tag{1} \end{equation}
    \begin{equation} \sum_{k=1}^{N}k=1+2+3+\cdots+N=\frac{N(N+1)}{2}\tag{2} \end{equation}
    \begin{equation} \sum_{k=1}^{N}k^2=1^2+2^2+3^2+\cdots+N^2=\frac{N(N+1)(2N+1)}{6}\tag{3} \end{equation}
    \begin{equation} \sum_{k=1}^{N}k^3=1^3+2^3+3^3+\cdots+N^3=\frac{N^2(N+1)^2}{4}\tag{4} \end{equation}
    🔗
    🔗

    Example 2.

    Calculate \(1+2+3+\cdots+100\text{.}\)
    🔗
    Solution.
    \begin{equation*} 1+2+3+\cdots+100=\sum_{k=1}^{100}k=\frac{100(100+1)}{2}=\frac{10100}{2}=5050. \end{equation*}
    🔗
    🔗
    🔗

    Example 3.

    Calculate \(1^2+2^2+3^2+\cdots+10^2\text{.}\)
    🔗
    Solution.
    \begin{equation*} 1^2+2^2+3^2+\cdots+10^2=\sum_{k=1}^{10}k^2=\frac{(10)(10+1)(2(10)+1)}{6}=\frac{(10)(11)(21)}{6}=385. \end{equation*}
    🔗
    🔗
    🔗

    Derivation 4 Finite Summation Properties.

    How do we combine these together to find something like \(\sum_{k=1}^{N}(k^2+2k)\text{?}\)
    🔗
    If \(f\) and \(g\) are functions and \(c\) is a real number, then
    \begin{equation} \sum_{k=1}^{N}cf(k)=c\sum_{k=1}^{N}f(k)\tag{5} \end{equation}
    \begin{equation} \sum_{k=1}^{N}\bigl(f(k)\mathbin{\pm}g(k)\bigr)=\sum_{k=1}^{N}f(k)\mathbin{\pm}\sum_{k=1}^{N}g(k)\tag{6} \end{equation}
    🔗
    🔗

    Example 5.

    Determine the value of \(\sum_{k=1}^{N}(k^2+2k)\text{.}\)
    🔗
    Solution.
    \begin{align*} \sum_{k=1}^{N}(k^2+2k)&=\sum_{k=1}^{N}k^2+\sum_{k=1}^{N}2k\\ &\quad\text{by the sum-addition property}\\ &=\sum_{k=1}^{N}k^2+2\sum_{k=1}^{N}k\\ &\quad\text{by the scalar-multiple property}\\ &=\frac{N(N+1)(2N+1)}{6}+2\left(\frac{N(N+1)}{2}\right)\\ &\quad\text{by the first-power and square-sum formulas}\\ &=\frac{N(N+1)(2N+1)}{6}+\frac{6N(N+1)}{6}\\ &=\frac{N(N+1)(2N+1+6)}{6}\\ &=\frac{N(N+1)(2N+7)}{6}. \end{align*}
    🔗
    🔗
    🔗

    Derivation 6 Approximating Area under a Curve.

    Why are we talking about this? How could we find the area under a curve?
    🔗
    How might we approximate this area?
    🔗
    Use \(N\) rectangles of width \(\Delta x=\frac{b-a}{N}\text{,}\) with right-end sample points \(x_k=a+k\Delta x\text{.}\) Then
    \begin{equation*} \text{area}\approx f(x_1)\Delta x+f(x_2)\Delta x+\cdots+f(x_N)\Delta x=\sum_{k=1}^{N}f(x_k)\Delta x, \end{equation*}
    which is a finite sum.
    🔗
    🔗

    Derivation 8 The Definite Integral.

    How do you make the approximation better? More rectangles imply that we take a limit.
    🔗

    Definition 9 Definite Integral.

    The definite integral of \(f\) over \([a,b]\) is
    \begin{equation*} \int_a^b f(x)\,dx=\lim_{n\to\infty}\left[\sum_{k=1}^{n}f(x_k)\Delta x\right]. \end{equation*}
    🔗
    🔗
    🔗

    Example 10.

    Use the definition of the definite integral to find the area under \(4x^3\) on \([0,3]\text{.}\) In other words, calculate \(\int_0^3 4x^3\,dx\text{.}\)
    🔗
    Solution.
    First, calculate the width \(\Delta x\) and sample points \(x_k\) for \(n\) rectangles:
    \begin{equation*} \Delta x=\frac{3-0}{n}=\frac{3}{n},\qquad x_k=0+k\left(\frac{3}{n}\right)=\frac{3k}{n}, \end{equation*}
    now, calculate the function values \(f(x_k)\text{:}\)
    \begin{equation*} f(x_k)=4\left(\frac{3k}{n}\right)^3=\frac{108k^3}{n^3}. \end{equation*}
    Putting this into the definition:
    \begin{align*} \int_0^3 4x^3\,dx&=\lim_{n\to\infty}\sum_{k=1}^{n}\left(\frac{108k^3}{n^3}\right)\left(\frac{3}{n}\right)\\ &=\lim_{n\to\infty}\sum_{k=1}^{n}\frac{324k^3}{n^4}\\ &=\lim_{n\to\infty}\left[\frac{324}{n^4}\sum_{k=1}^{n}k^3\right]\\ &=\lim_{n\to\infty}\left[\frac{324}{n^4}\cdot\frac{n^2(n+1)^2}{4}\right]\\ &=\lim_{n\to\infty}81\left(1+\frac{2}{n}+\frac{1}{n^2}\right)\\ &=81. \end{align*}
    🔗
    🔗
    🔗

    Example 11.

    Evaluate \(\int_2^4(2x-6)\,dx\) using the definition of the definite integral.
    🔗
    Solution.
    First, calculate the width \(\Delta x\) and sample points \(x_k\) for \(n\) rectangles:
    \begin{equation*} \Delta x=\frac{4-2}{n}=\frac{2}{n},\qquad x_k=2+k\left(\frac{2}{n}\right)=2+\frac{2k}{n}, \end{equation*}
    now, calculate the function values \(f(x_k)\text{:}\)
    \begin{equation*} f(x_k)=2\left(2+\frac{2k}{n}\right)-6 = \frac{4k}{n}-2\text{.} \end{equation*}
    Putting this into the definition:
    \begin{align*} \int_2^4 2x - 6 \,dx \amp = \lim_{n\to\infty}\sum_{k=1}^{n}\left(\frac{4k}{n}-2\right)\left(\frac{2}{n}\right)\\ \amp = \lim_{n\to\infty}\sum_{k=1}^{n}\left(\frac{8k}{n^2}-\frac{4}{n}\right)\\ \amp = \lim_{n\to\infty}\left( \frac{8}{n^2} \sum_{k=1}^{n} k - \frac{4}{n} \sum_{k=1}^{n} 1 \right)\\ \amp = \lim_{n\to\infty}\left( \frac{8}{n^2} \frac{n(n+1)}{2} - \frac{4}{n} n\right)\\ \amp = \lim_{n\to\infty}\left( 4 \frac{n+1}{n} - 4\right)\\ \amp = \lim_{n\to\infty}\left( 4 \left(1 + \frac{1}{n} \right) - 4\right)\\ \amp = 4(1+0)-4\\ \amp = 4-4\\ \amp = 0\text{.} \end{align*}
    🔗
